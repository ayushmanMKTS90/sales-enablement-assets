How to Use This Dashboard

A quick guide on how to edit competitors, use Excel, and win more sales calls with cheat sheets.

1

1. Editing the Table

Just click on any name, price, or score to type new numbers. Click on any green/yellow/red button to flip between Yes, Partial, and No. Everything saves automatically.

2

2. Using Excel

Click Download Excel File from the Menu whenever you want a copy. You can make changes in Excel or Google Sheets, then click Upload Excel File to pull those changes back in.

3

3. Using the Cheat Sheets on Sales Calls

When a buyer brings up a competitor, open that competitor's cheat sheet. You'll get a 30-second pitch, questions to ask the buyer that reveal the competitor's weak spots, and a ready-made comeback line.
